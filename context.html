1. ภาพรวมโปรเจกต์

พัฒนาระบบ AMSS++ / SMSS (Smart Management Support System สำหรับสำนักงานเขตพื้นที่การศึกษา) ใหม่ทั้งหมดด้วย Next.js + PostgreSQL สำหรับ สำนักงานเขตพื้นที่การศึกษาประถมศึกษาชัยนาท (สพป.ชัยนาท) โดย deploy บน เซิร์ฟเวอร์ภายในเขต (on-prem) ไม่ใช้ Vercel/cloud เป็น production

เป้าหมาย production: โดเมน amsscnt.com (หรือ URL ภายในเขต) บน Linux + Nginx + Node.js + PostgreSQL

ไฟล์อ้างอิงหลักใน repo นี้

ไฟล์บทบาทสถานะ
context.html เอกสาร context นี้ — ใช้ @ mention ใน Cursor เมื่อ build with doc พร้อมใช้งาน
ระเบียบงานสารบรรณ ฉบับปรับปรุง พ.ศ. 2546 มาตรฐานราชการหลัก — lock แล้ว (§4.1, §12); ไม่มีไฟล์ใน repo — อ้างอิงข้อความระเบียบภายนอก lock
